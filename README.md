# Kamex Soluciones — Landing

Landing de Kamex Soluciones (desarrollo de software a medida en Argentina), hecha con Vite + React.

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

Genera la carpeta `dist/`, lista para desplegar (Vercel la detecta automáticamente como proyecto Vite).
